# SepReformer baseline, Libri2Mix 16 kHz

This package now targets Libri2Mix wav16k/min train-100/dev/test by default.
It uses the same modern training protocol as the VN-SpeechMix baseline and LTRR.
See [shared protocol, data preparation and commands](../../docs/COMMON_16K_PROTOCOL.md).

This is a NEW from-scratch experiment. The historical course-project baseline
with batch 12 and kernel 16 is preserved under `legacy/libri2mix_16k/`.
